# M3 통계 정의 (수식)

코드: `packages/core/src/mdd/mdd.ts`. 배치와 브라우저가 같은 코드를 쓴다.

## 1. 입력
- 가격 $c_t$: **수정주가 종가**(분할·배당 조정, D3). 출처가 주는 수정 기준을 따른다(Stooq C급, Tiingo `adjClose` B급).
- 기간: 종목별 상장일부터 받을 수 있는 최대 기간(D5). 화면에 종목별 시작일을 표시한다.
- 고가·저가는 출처마다 수정 여부가 달라 통계에는 **종가만** 쓴다(차트·52주 범위 표시에만 고가·저가 사용).

## 2. 연간 기준일과 연도 구간
- 주식: 시장별 매년 첫 거래일(D4). BTC: 매년 1월 2일(2절).
- 연도 $y$의 구간 $[b_y, b_{y+1})$: 기준일 $b_y$ 봉부터 다음 해 기준일 직전 봉까지. 다음 해 기준일이 없으면 마지막 봉까지(진행 중 연도).
- **완결 연도**: 다음 해 기준일이 있고, 데이터 첫 해라면 첫 봉이 그 해 기준일과 같아야 한다(상장 연도 등 중간 시작 연도 제외). 평균·빈도표는 완결 연도만 쓴다.

## 3. 연도별 지표 ($c_b$ = 기준일 종가)
| 지표 | 수식 |
|---|---|
| 상승률(기준일 대비 연중 최고) | $U_y = \max_{t\in y} c_t / c_b - 1$ |
| 낙폭(기준일 대비 연중 최저) | $D_y = \min_{t\in y} c_t / c_b - 1$ |
| 연중 MDD | $M_y = \min_{t\in y}\left( c_t / \max_{b\le s\le t} c_s - 1 \right)$ |
| 연간 수익률 | $R_y = c_{\text{마지막}} / c_b - 1$ |

- 평균상승률·평균낙폭·평균MDD·평균수익률 = 완결 연도의 산술평균. 추가 통계: 중앙값 MDD, 최악 MDD, 상승 연도 비율.
- **연중 MDD 구간별 빈도표**: 사용자 기존 엑셀의 구간을 따른다. 낙폭 크기 $m=-M_y$로 "5% 이하"($0\le m\le5$), "5% ~ 10%", "10% ~ 15%", "15% ~ 25%", "25% ~ 35%", "35% ~ 50%", "50% ~ 60%", "60% ~ 70%", "70% ~ 80%"(각 $(하한, 상한]$), "80% 이상"($m>80$). 경계값 10%는 "5% ~ 10%". 비율 = 횟수 ÷ 완결 연도 수.

## 4. 고점 대비 하락률(현재)
- 고점 기간 $W$(52주·3년·5년·10년·올해·전체·직접 선택): $DD = c_{\text{최신}} / \max_{t\in W} c_t - 1$.
- 역대 일별 낙폭 백분위: 전체 기간 누적 고점 기준 일별 낙폭 $dd_t$ 중 현재 값 이하인 날의 비율.
- 최장 수중 기간: $dd_t < 0$이 연속된 최대 거래일 수.

## 5. 백테스트(참고)
- 진입: 누적 고점 대비 $dd_t \le$ 진입낙폭이면 전액 매수(편도 수수료 차감).
- 청산: 진입 시점의 누적 고점 회복 또는 목표 수익, 선택 시 손절.
- 세금: 사용자가 세율을 입력했을 때만 실현 이익에 적용(기본값 없음 — 공식 출처 확인 전).
- 원화 환산: FRED DEXKOUS(직전 영업일 값) 곱.

## 6. 엑셀 재현 상태(2026-11-23, 사용자 엑셀 제공)
- 로컬 검사 `python scripts/excel_check.py`(엑셀은 `private/`에만, 결과 요약만 기록):
  - **빈도표**: 엑셀의 연도별 MDD 목록을 웹앱 공용 빈도표 함수에 넣으면 모든 시트에서 빈도 수가 정확히 일치. 일부 시트의 마지막 구간 수식이 다른 구간을 세는 오류가 있어 그 행은 비교에서 뺐다(웹앱은 80% 초과를 셈).
  - **평균 MDD 집계**: 엑셀 안의 요약 값과 연도별 평균의 최대 차이 0.0034%p(허용 0.01%p) — 엑셀 정의를 바르게 읽었는지 확인하는 검사이며, 웹앱 계산값과의 비교는 아님.
  - **같은 가격 데이터로 재현**: 개발 환경에서 외부 시세 접속 불가로 보류. `private/prices/<종목>.csv`(Date·Open·High·Low·Close)를 넣으면 엑셀 정의로 다시 계산해 비교한다. 준비 방법: README '엑셀 가격 재현(선택)'.
- **엑셀과 웹앱의 정의 차이**(11절 7번, 결정 전까지 웹앱은 D3·D4 확정 정의 유지):
  1. 가격: 엑셀은 배당 미반영 / 웹앱 수정주가(D3)
  2. 연간 기준값: 엑셀 첫 거래일 시가 / 웹앱 첫 거래일 종가(D4)
  3. 연중 최고·최저: 엑셀 장중 고가·저가 / 웹앱 종가
  4. 연중 MDD: 엑셀은 연중 최고가와 최저가의 차이(순서 무관) / 웹앱은 고점 이후 저점(시간 순서)
  5. 표본: 엑셀은 첫해·진행 중 연도 포함 / 웹앱은 완결 연도만
  6. 고점 대비 현재: 엑셀은 장중 최고가 기준 / 웹앱은 기간별 종가 최고 기준
  7. 암호화폐: 엑셀 안에서도 요약과 상세의 계산 방식이 조금 다름
  8. 낙폭 0%인 해: 엑셀 빈도표는 세지 않음(조건 >0) / 웹앱은 "5% 이하"에 셈(비율 합계 100%를 맞추기 위해)

### 수작업 검산 예시 1 (미국 주식)
종가: 2024-01-02 100 → 03-01 120 → 06-03 90 → 12-31 110 / 2025-01-02 110 → 05-01 77 → 12-31 121 / 2026-01-02 121
- 2024: $U=120/100-1=20\%$, $D=90/100-1=-10\%$, $M=90/120-1=-25\%$, $R=10\%$
- 2025: $U=121/110-1=10\%$, $D=77/110-1=-30\%$, $M=77/110-1=-30\%$
- 평균: 상승률 15%, 낙폭 −20%, MDD −27.5%. 빈도표: "15% ~ 25%" 1회(25%는 경계값), "25% ~ 35%" 1회

### 수작업 검산 예시 2 (BTC, 기준일 1월 2일)
2023-01-02 100 → 06-01 50 → 12-31 200 → 2024-01-01 210(2023 구간) / 2024-01-02 200 → 12-31 150
- 2023: $U=110\%$, $D=-50\%$, $M=-50\%$, $R=110\%$ / 2024: $M=-25\%$ → 평균MDD −37.5%

### 수작업 검산 예시 3 (백테스트)
100, 80, 60, 90, 100, 110 → −30% 진입은 60(−40%)에서, 전고점 100 회복 시 청산: 수익률 $100/60-1=66.67\%$. 수수료 10bp: $0.999^2\times100/60-1$. 세율 20%: $66.67\%\times0.8$.
