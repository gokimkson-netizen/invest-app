# 11절 사용자 확인 필요 목록 (2026-11-23 개발 결과 기준)

형식: 결론(권장안) → 왜 필요한지 → 선택지

1. **무료 인증키 발급** — 권장: README 1단계 표대로 발급. 키가 없으면 해당 데이터만 '데이터 없음'으로 표시되고 나머지는 동작. 선택지: 지금 발급 / 일부만 발급.
2. **KRX 약관 검토 결과(D6)** — 결론: 자동 수집 금지(제10조②2호) → 국내 수급 미구현. 대안: ① 그대로 '제공 안 됨'(권장) ② KRX에 사전 허락 요청 후 구현 ③ 증권사 오픈API(메리츠 출시 후) 수급 조회를 PC 프로그램에서 받아 로컬 표시.
3. **Cloudflare Workers 무료 플랜 과금 위험(D8)** — 결론: 결제 수단 없이 Free 사용, 한도 초과 시 오류(과금 없음). Durable Objects도 Free에서 SQLite 기반만 사용(초과 시 오류). 권장: 결제 수단 미등록 유지.
4. **M1 일일 배치 소요 시간·Gemini 요약 호출 수** — 개발 환경에서 실측 불가(외부 접속 차단). 추정: 일상 실행 수 분, 첫 실행 20~40분, 요약 대기열 약 1,200건을 하루 100건씩 약 12일(추측입니다). 첫 배포 후 실측해 보고.
5. **G6 '판단불가' 비율** — 실측 전. 구조상 경영진 판단 근거가 DEF 14A 발췌뿐이라 판단불가가 많을 수 있음. 결정표는 바꾸지 않았음. 선택지: ① 그대로 ② G6 판단불가를 감점(조건부)으로만 처리하는 규칙 변경.
6. **국내 종목 M1 즉시 분석 필요 여부** — 현재 미국만(D7). 권장: 현행 유지.
7. **MDD 엑셀 정의 차이(엑셀 재현 결과)** — 빈도표 구간을 엑셀 구간으로 바꿨고, 엑셀의 연도별 MDD를 웹앱 빈도표 함수에 넣으면 빈도 수가 정확히 일치합니다. 엑셀 정의 해석도 엑셀 안의 값으로 확인했습니다(웹앱 계산값과의 직접 비교는 같은 가격 데이터가 필요해 보류 — 가격 CSV를 넣으면 실행). 정의가 다른 8가지는 `docs/mdd-definitions.md` 6절. 엑셀 일부 시트의 마지막 구간 수식 오류도 발견. 선택지: ① 웹앱 정의 유지(권장, D3·D4와 같음) ② 화면에 '엑셀 방식' 값을 함께 표시 ③ 엑셀 방식으로 교체(D3·D4 변경 필요).
8. **M6 중요도 규칙 초안·설명 경로 템플릿** — `config/news_rules.json`, `config/news_explain.json`. 확인 요청 항목: 사건 유형 13개, 기본 등급, 시총 상위 20종목 한 단계 가중, C급 단독 최대 '보통', 지표 임계(CPI 전월비 0.5%, 고용 15만 명, PCE 0.5%), 동의어·부정 표현.
9. **Worker용 OpenDART 키 별도 발급 가능 여부** — 계정당 1개면: ① 다른 계정으로 1개 더(권장, 약관 확인 필요) ② Worker 국내 즉시 분석 비활성화.

## 개발 중 새로 생긴 확인 항목
10. **국내 가격(D17)** — Stooq의 국내 종목 지원 여부를 개발 환경에서 확인할 수 없었음. 미지원이면 코스피 M3·M2 주가가 '데이터 없음'. 무료·약관 허용·수정주가·전체 기간을 모두 만족하는 국내 출처를 찾지 못함(KRX·공공데이터포털은 재배포/자동 수집 제한). 선택지: ① '데이터 없음' 유지 ② 비공식 출처를 사용자 책임으로 사용 ③ 국내 M3 범위 축소.
11. **확신도 '상' 조건** — '핵심 근거 모두 A급'에 가격 출처 등급을 넣었기 때문에 Stooq(C급) 사용 중에는 '상'이 나오지 않음. 선택지: ① 그대로(엄격) ② 재무·공시 근거만으로 판단.
12. **증분 ROIC 정의 불가(투하자본 증가 ≤ 0)** — 검수 후 **판단불가로 변경**(값을 지어내지 않음, G4 근거에 '정의 불가' 표시). 선택지: ① 그대로(권장) ② 이익 증감으로 대신 판정 ③ 해당 지표 제외.
13. **은행·보험 업종 지표** — CET1·대손비용률·합산비율·지급여력비율은 SEC companyfacts에 표준 태그가 없어 금융업 G2·G5가 '판단불가'가 됨. 선택지: ① 그대로 ② 금융업 종목을 M1에서 제외 ③ 수동 입력.
14. **무한매수법 V4.0 규칙 반영** — 문서를 받아 비공개 규칙 파일·대응표·문서 예시 테스트를 만들었고 예시 테스트는 모두 통과했습니다. 문서에 정해져 있지 않거나 예시끼리 다른 부분(사다리 개수, 첫 매수 할증률 선택, 일부 예시의 수량·가격 차이, 리버스 모드 세부 해석, 주문 거부 대응)은 비공개 대응표(`private/infinite-v4-mapping.md`) 끝에 정리했습니다. 선택지: 각 해석을 그대로 둘지, 다르게 정할지.
15. **국내 휴장일 등급** — 국내 2026·2027 휴장일은 정리 페이지(C급)+언론(B급)으로 확인. KRX 공지로 한 번 확인 권장.

## 검수 후 추가된 확인 항목
16. **이자부부채 태그 없음 → null** — 부채 태그가 하나도 없는 회사는 부채를 0으로 보지 않고 '데이터 없음'으로 둠. 투하자본·ROIC·부채비율이 비어 G4·G5가 판단불가가 늘 수 있음. 선택지: ① 그대로(권장, 지어내지 않음) ② 부채 0 간주(실제 부채가 있으면 ROIC 과대).
17. **실효세율 대체** — 어떤 해의 실효세율을 계산할 수 없으면(세전이익 ≤ 0 등) 다른 해 평균 실효세율로 대체하고 'ROIC 세율 대체' 표시. 선택지: ① 그대로 ② 그 해 ROIC를 판단불가 처리.
18. **G2 '형편없는 사업' 유형** — 부록 A에 정량 정의가 없어 코드가 따로 판정하지 않음(ROIC 구간으로만 판정, '데이터부족' 표시). 선택지: ① 그대로 ② 판정 기준을 수치로 정해 주시면 코드화.
19. **Wikipedia 구성종목(C급)** — Wikimedia 정책상 User-Agent에 연락처가 필요해 `WIKI_USER_AGENT`(선택) 또는 SEC 연락처를 보냄(하루 2건, 직렬). 내용은 CC BY-SA 4.0 → 화면에 출처·라이선스·수집일 표시. 첫 실행에 실패하면 그 지수는 빠지고 다음 실행에서 재시도. 선택지: ① 그대로 ② 별도 연락용 이메일·주소를 `WIKI_USER_AGENT`로 등록(권장).
20. **버크셔 참고 정보의 한계** — 13D/13G는 목록·원문 링크만(대상 회사·수량 자동 해석 안 함). 분기 말 이후 주식 분할은 보정하지 않아 '현재 추정 평가액'이 틀릴 수 있음. 주식 클래스(A/B)는 CUSIP별로 따로 집계. 화면에 명시함. 판정에는 반영하지 않음.
21. **배포 후 실측(README 5-1단계)** — 뉴스 24시간 실행률·지연, 취소 실행 0건, 뉴스 배포 뒤 다른 모듈 유지, publish 잡 소요 시간을 첫 배포 다음 날 확인해 `docs/design.md` 11절 표에 기록.
22. **M5 운용 규칙 파일** — 앱은 규칙 값을 정하지 않음. 규칙 파일(JSON)을 불러오면 형식을 검사하고, 조건에 맞는 구간을 **모두** 표시(어느 구간을 실행할지 고르지 않음). '확정: false'면 '규칙 미확정(참고)'로 표시.
23. **무한매수법 규칙 파일 전달** — 규칙 파일은 공개 저장소에 넣지 않으므로 업로드용 압축과 따로 드립니다(비공개 파일 묶음). 내 PC 프로젝트의 `private/` 폴더에 풀고, 앱의 무한매수법 화면에서 규칙 파일을 불러오세요. 다른 기기에는 암호화 동기화로 전달됩니다.
